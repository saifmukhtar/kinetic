# Kinetic End User Documentation

Welcome to Kinetic! Kinetic is a decentralized naming engine that allows you to register secure, censorship-resistant names (like `myname.kin`). 

With Kinetic, you can:
- **Register `.kin` names** that you permanently own without paying recurring fees.
- **Browse `.kin` websites** natively by running the Kinetic daemon on your machine.
- **Create a cryptographic identity** to secure your digital footprint and data.

## Where do I start?

To get started, you'll need to install the Kinetic daemon on your computer. Choose your operating system below:
