# Privacy Policy

**Last Updated:** July 17, 2026

## 1. Information We Collect
Kinetic is a fully decentralized, stateless peer-to-peer network. As a core principle, **we do not collect, store, or process any personal data.** 
When you use the Kinetic protocol, you communicate directly with other peers. There are no central servers logging your IP addresses, domain registrations, or browsing history.

## 2. Telemetry and Analytics
The Kinetic website (`kinetic.saifmukhtar.dev`) and documentation do not use any tracking cookies, third-party analytics (like Google Analytics), or telemetry. We only utilize standard web hosting access logs for security and abuse prevention.

## 3. The Kinetic Protocol
Because the protocol relies on VDFs (Verifiable Delay Functions) and cryptographic proofs on a DHT (Distributed Hash Table), the information you publish to the network (e.g., your `.kin` domain routing records) is inherently public and propagated to other nodes. This data is public by design.

## 4. Third-Party Links
Our documentation and website may contain links to third-party websites (e.g., GitHub). We are not responsible for the privacy practices of those external sites.

## 5. Contact Us
For any privacy-related inquiries, please open an issue on the [Kinetic GitHub Repository](https://github.com/saifmukhtar/kinetic).
